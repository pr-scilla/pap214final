# Stream Chemistry Changes Pre and Post Hurricane Hugo: Analytical Workflow for Reproducing a Figure

## Purpose
The purpose of this repository is to house the analytical workflow for reproducing figure 3 from [Schaefer et al. (2000)](#references), which shows stream chemistry changes in four Puerto Rican streams pre and post Hurricane Hugo.

The analytical workflow housed in this repository is the final project for **EDS 214: Analytical Workflows and Scientific Reproducibility**. 

## pap214final Repository Contents

Data reading and cleaning is performed in 1_clean_data.R. 

This repository is split into directories that house information used in data analysis and figure generation for replicating figure 3 from [Schaefer et al. (2000)](#references).

Descriptions of these directories are found in the following sections:

## data Directory

Raw data .csv files used in this analysis were sourced from [McDowell and International Institute Of Tropical Forestry (IITF) (2024)](#references) and are contained in [data](https://github.com/pr-scilla/pap214final/tree/main/data). 

Units for water chemistry data were sourced from **LUQ_LTER_MDLs.csv**.

Raw water chemistry data for the four sample sites of interest (BQ1, BQ2, BQ3, and PRM) were sourced from **QuebradaCuenca1-Bisley.csv**, **QuebradaCuenca2-Bisley.csv**, **QuebradaCuenca3-Bisley.csv**, and **RioMameyesPuenteRoto.csv**, respectively.

## docs Directory

The rendered version of the [Stream Chemistry Changes Pre and Post Hurricane Hugo](https://pr-scilla.github.io/pap214final/paper.html) page is contained in [docs](https://github.com/pr-scilla/pap214final/tree/main/docs).

## figs Directory

The Figure 3 reproduction generated by this analysis is housed in the [figs](https://github.com/pr-scilla/pap214final/tree/main/figs) directory.
